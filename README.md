# ศาลาใจ

เว็บให้ผู้มีทุกข์ใจคุยระบายกับ "เพื่อนธรรม" ผู้ช่วย AI ที่ตอบด้วยหลักพุทธจิตวิทยา โดยไม่ต้องสมัครสมาชิก
ดูแลโดยพระมหาธนพล กุสลฏฺฐายี วัดสุทัศนเทพวราราม

## มีอะไรบ้าง

- คุยกับเพื่อนธรรม (AI) ได้ทันที ไม่ต้องมีบัญชี
- ความปลอดภัย: ถ้าข้อความส่อว่าจะทำร้ายตัวเอง จะขึ้นสายด่วน 1323, 1669 และสมาริตันส์ทันที และสั่งให้ AI ให้ความปลอดภัยมาก่อน
- ความเป็นส่วนตัว: ไม่เก็บบทสนทนาไว้ที่เซิร์ฟเวอร์ และไม่บันทึกข้อความลง log
- หน้าติดต่อพระอาจารย์ (โทรได้ทันทีจากมือถือ)
- ฝึกอานาปานสติ 3 นาที
- จำกัดการส่งข้อความต่อเครื่อง (30 ครั้งต่อ 10 นาที) และความยาวข้อความ เพื่อกันการใช้เกินจำเป็น

## นำขึ้นออนไลน์ด้วย Vercel (แนะนำ)

1. สร้างบัญชีที่ https://console.anthropic.com เติมเครดิต และสร้าง API key
2. นำโค้ดนี้ขึ้น GitHub
3. ที่ https://vercel.com กด Add New → Project แล้วเลือก repository นี้
4. ใน Environment Variables ใส่ `ANTHROPIC_API_KEY` เป็น key จากข้อ 1
5. กด Deploy จะได้ลิงก์เว็บที่ใครก็เปิดใช้ได้

ค่าใช้จ่ายของ AI คิดตามการใช้งานจริง ควรตั้งวงเงินรายเดือน (spend limit) ใน console.anthropic.com

## ตั้งค่าเพิ่มเติม

| ตัวแปร | ความหมาย |
|---|---|
| `ANTHROPIC_API_KEY` | จำเป็น |
| `CLAUDE_MODEL` | รุ่นของ AI ค่าเริ่มต้น `claude-opus-5-5` |

แก้ชื่อ วัด และเบอร์โทรได้ที่ `lib/site.ts` แก้วิธีตอบของเพื่อนธรรมได้ที่ `lib/prompt.ts`

## รันบนเครื่อง

```bash
npm install
cp .env.example .env.local   # แล้วใส่ ANTHROPIC_API_KEY
npm run dev
```
